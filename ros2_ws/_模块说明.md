# 模块说明：ros2_ws —— 树莓派 ROS2 工作区

| 项 | 内容 |
|---|---|
| 中文名 | 上位机 ROS2 工作区（colcon workspace） |
| 一句话 | 跑在树莓派 5 上的 ROS2 代码：桥接节点把 `/cmd_vel` 变成串口帧发给 STM32，再把串口遥测变成 `/odom` + TF；另外含仿真包和零硬件测试工具 |
| 跑在哪 | `src/stm32_bridge` → **树莓派 5**（Ubuntu 24.04 + ROS2 Jazzy）；`src/omninav_sim` → 虚拟机/PC（Gazebo Classic 11）；`tools/` → PC 开发机 |
| 构建方式 | `colcon build`（本工作区根目录），不要手工拷包 |

## 三个子目录

| 子目录 | 中文名 | 作用 | 入口 |
|---|---|---|---|
| `src/stm32_bridge/` | **串口-ROS2 桥接包** | 订阅 `/cmd_vel` → 协议帧写串口；读串口 → 解帧 → 发布 `/odom`、TF(`odom→base_link`)、状态 | `ros2 run stm32_bridge stm32_bridge`（entry point：`stm32_bridge.bridge_node:main`） |
| `src/omninav_sim/` | **Gazebo 仿真包**（新增，尚未提交 git） | URDF + 轮子/底盘几何、warehouse world、launch；用 `planar_move` 插件代替真实麦轮 | `ros2 launch omninav_sim gazebo.launch.py`（无界面加 `gui:=false`） |
| `tools/` | **零硬件开发工具** | `fake_stm32.py` 假下位机、`run_e2e.py` 端到端、`check_core.py` 跨语言对拍 | `python3 tools/run_e2e.py` 等 |

## 桥接包内部文件

| 文件 | 作用 |
|---|---|
| `stm32_bridge/bridge_node.py` | 节点主体：串口打开、收发线程、`/cmd_vel` 回调、`/odom` 与 TF 发布、超时保护 |
| `stm32_bridge/kinematics.py` | 麦轮正/逆解（Python 侧，与 `firmware_core` 对拍用） |
| `stm32_bridge/protocol.py` | 串口整数文本协议编解码 |
| `test/test_protocol.py` | 协议回归：46 用例 / 153 断言 |

## 常用命令

```bash
# 构建（在 ros2_ws 根）
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install

# 跑桥接（真串口）
source install/setup.bash
ros2 run stm32_bridge stm32_bridge

# 零硬件整链路（PC 上，Humble/Jazzy 均可）
python3 tools/run_e2e.py

# 仿真
ros2 launch omninav_sim gazebo.launch.py gui:=false
```

## 约束

- 话题/坐标只有标准接口：`/cmd_vel`、`/odom`、`/scan`、`/tf`、`/map`；单位 m、rad（对外）与 mm、mrad（串口）在桥内换算，**不要在别处再换算一次**。
- 版本三件套：ROS2 **Jazzy** + `ROS_DOMAIN_ID=42` + `RMW_IMPLEMENTATION=rmw_cyclonedds_cpp`。
- 跑 `run_e2e.py` 时**不要**同时开 `stm32_bridge`（会抢同一个串口/话题）。
- 树莓派 2 GB 内存：不跑 rviz2 / Gazebo / Docker；仿真只在 PC 或虚拟机上做。
