# 模块说明：firmware_core —— 算法核心（纯逻辑算法层）

| 项 | 内容 |
|---|---|
| 中文名 | 算法核心 / 纯逻辑算法层 |
| 一句话 | 麦轮运动学、里程计、PID、定点运算、串口协议解析：**平台无关的 C99 代码，不含任何硬件依赖** |
| 跑在哪 | ① 被编进 STM32 固件（`stm32_fw/MDK-ARM/OmniNav_STM32.uvprojx` 已把本目录 5 个 `.c` 加入编译）；② 在 PC/树莓派上 `make lib` 编成 `build/libomninav_core.so`，供 Python 桥接与跨语言对拍 `ctypes` 调用 |
| 谁改 | 只有算法改动才动这里；动之前先确认不影响 `stm32_fw/` 的编译和 Python 对拍 |

## 关键文件

| 文件 | 作用 |
|---|---|
| `include/fixedpoint.h` | Q 格式定点类型与乘除、饱和、三角函数近似 |
| `include/mecanum.h` | 麦轮正/逆运动学、几何参数（**几何唯一来源**） |
| `include/odom.h` | 三轮/四轮里程计积分、位姿重置 |
| `include/pid.h` | 定点 PID（含抗饱和） |
| `include/protocol.h` | 串口整数文本协议：组帧、解帧、校验 |
| `src/*.c` | 上述实现，共 5 个文件 |
| `test/test_*.c` | 宿主机单元测试（25344 条判据） |
| `Makefile` | `check-purity` / `lib` / `test` / `test-asan` / `clean` |

## 编译与测试（WSL Ubuntu 22.04）

```bash
cd firmware_core
make check-purity   # 纯净性：禁止 HAL/ROS2/第三方头、禁止浮点
make lib            # 生成 build/libomninav_core.so（-fPIC -shared -O2 -std=c99）
make test           # 单元测试，必须 0 failures
make test-asan      # 地址消毒版回归
```

## 硬性约束（违反即破坏契约，见《11_接口契约》§五、§六）

1. **7 个导出符号冻结**：`mecanum_forward` / `mecanum_inverse` / `mecanum_l_mm` / `mecanum_default_geom` / `mecanum_geom_is_valid` / `odom_update` / `odom_reset`。不得改名、改签名、改单位。
2. `src/`、`include/` **禁止** include `stm32f1xx_hal*.h`、ROS2 头、任何第三方头；只能 include 标准 C 头 + 本目录头。
3. **禁止浮点**：算法层全部整数/定点（`-Wconversion -Wshadow -Wcast-qual` 等警告视为错误）。
4. **几何数字只写一处**：轮径 80 mm、半轴距/半轮距占位 150/150 mm（待实测替换）、编码器 10505 计数/米（1:60；若 1:56 则 9806）。任何地方不得再抄第二份。
5. `.so` 查找顺序固定：`OMNINAV_CORE_SO` 环境变量 → 包内 `lib/` → `/opt/omninav/lib/`，找不到必须明确报错，不许静默降级。
