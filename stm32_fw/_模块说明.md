# 模块说明：stm32_fw —— STM32 底盘固件

| 项 | 内容 |
|---|---|
| 中文名 | STM32 底盘固件（下位机） |
| 一句话 | 跑在 STM32F103ZET6 上的实时底盘固件：电机 PWM/方向、串口协议收发、算法调用、上电安全默认态 |
| 跑在哪 | **STM32F103ZET6**（LQFP144，512 KB Flash / 64 KB SRAM，72 MHz，无 FPU）；开发环境 Keil MDK 5.34 + STM32CubeMX 6.17 |
| 谁改 | 下位机行为（引脚、状态机、时序、安全策略、串口帧）都在这里；上位机不要为了迁就固件去改协议 |

## 关键文件

| 文件 | 作用 |
|---|---|
| `MDK-ARM/OmniNav_STM32.uvprojx` | Keil 工程（唯一入口，相对路径引用 `../Src`、`../../firmware_core`） |
| `Src/main.c` | 主入口：上电默认进 USART2 链路自证；3 秒内在 USART1 按 `m` 进电机台架 |
| `Src/usart2_bench.c` | USART2（PA2/PA3 → 树莓派）链路自证：协议收发、心跳、统计帧 |
| `Src/bench.c` | 电机台架：单/多电机开环试转，用于接线与方向确认 |
| `Src/core_selftest.c` | 算法层上板自检（期望值抄自 `firmware_core/test/`） |
| `Src/app_single_wheel.c` + `Inc/app_single_wheel.h` | **A-02 单轮安全固件**：编译期开关 `OMNINAV_APP_SINGLE_WHEEL`（默认 0 = 不改变原行为），含安全五件套 |
| `Src/stm32f1xx_hal_msp.c` / `stm32f1xx_it.c` / `system_stm32f1xx.c` | CubeMX 生成的外设初始化、中断向量、时钟 |

## 引脚与安全（不要把这几条改错）

| 项 | 值 |
|---|---|
| 电机 M1 | PWM `PE9`、AIN1 `PE7`、AIN2 `PE8` |
| 电机 M2 | PWM `PE11`、AIN1 `PE10`、AIN2 `PE12` |
| 电机 M3 | PWM `PE13`、AIN1 `PD0`、AIN2 `PD1` |
| 电机 M4 | PWM `PE14`、AIN1 `PD8`、AIN2 `PD9` |
| STBY | `PE15`（两片 TB6612 共用；低=待机滑行，高=使能） |
| 上电默认 | STBY=0、PWM=0、IN=0（高阻滑行，**不会自己动**） |
| 命令超时 | `OMNINAV_CMD_TIMEOUT_MS` = 200 ms（超时撤输出并锁存 DISABLED，需 `g` 重使能） |
| 占空比限幅 | `OMNINAV_APP_DUTY_MAX` = 50 % |
| PWM 频率 | `APP_PWM_ARR` = 3599 → 20.000 kHz；换向死区 5 ms |
| 单轮调试命令 | 单字符：`f` 前进 / `r` 后退 / `g` 使能 / `k` 停止 / `b` 刹车 / `s` 状态 / `p` 参数 / `?` 帮助 |

## 编译与烧录

1. Keil MDK 5.34 打开 `MDK-ARM/OmniNav_STM32.uvprojx` → `Build`（0 Error 0 Warning）。
2. 烧录**只走 ST-Link**（Keil Flash Download 不认 CH340；用 ST-Link Utility/Keil 均可），烧完看串口 banner。
3. 单轮固件要试车时：工程 `Options → C/C++ → Define` 加 `OMNINAV_APP_SINGLE_WHEEL=1` 重编。
